# PoC 4 - Reforestación, terreno y presentación

**Pregunta:** ¿El paso de ceniza a verde es una recompensa visible y la reforestación entretiene por sí sola?

**Criterio de éxito:** Mapa de 10 000+ tiles pasa de gris a verde sin caídas de FPS; cambio de fase completo; música por capas.

## Correr

```bash
npm install          # desde la raíz del monorepo
npm run dev:terreno
```
