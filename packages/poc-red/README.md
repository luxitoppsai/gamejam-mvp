# PoC 3 - Multijugador en línea

**Pregunta:** ¿Podemos sincronizar 4 jugadores y un mapa compartido con servidor autoritativo y baja latencia percibida?

**Criterio de éxito:** 4 clientes estables 10 min; cuadrícula idéntica (checksum); ancho de banda y latencia medidos.

## Correr

```bash
npm install          # desde la raíz del monorepo
npm run dev:red
```
